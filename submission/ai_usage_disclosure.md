# AI 使用披露（AI Usage Disclosure）

> 核心原则：**"用 AI 造工具"与"工具里跑 AI"是两件事，必须分开陈述。**

## 一、开发期（是）

| 项 | 内容 |
|---|---|
| 使用的工具 | WorkBuddy（编程 Agent），模型面板显示为 DeepSeek-V4.1-Flash 系列 |
| 用途 | 需求拆解与假设记录、几何推导与实现、React/SVG 交互实现、测试编写、文档撰写、Git 提交与发布尝试 |
| 人类作者的角色 | 提出需求与约束、指定品牌与预算边界、审阅关键决策、决定"不做假 AI"等取舍 |
| 生成内容 | 代码、测试、文档、文案草稿；均经人工审阅与自动化测试把关 |

**开发期使用 AI 不影响作品的可信度判断**：每一处几何结论都由 `src/tests/*.test.ts` 的断言验证，
而不是由模型"声称正确"。若断言不成立，代码就是错的——这与作者是谁无关。

## 二、运行期（否）

| 项 | 结论 |
|---|---|
| 作品运行时是否调用大模型 | **否** |
| 是否有 AI 相关入口 | **否**（界面里没有按钮、没有隐藏开关） |
| 是否需要用户提供 API Key | **否** |
| 是否向任何服务器发送用户数据 | **否**（无网络请求；字体为系统字体，无 CDN） |
| 断网 / 限流 / 模型下线的影响 | **无** |

图案全部由 `src/geometry` 的确定性算法生成：相同输入 → 相同输出（有专门的确定性测试）。

## 三、为什么没有做运行时 AI

需求文档把"AI 灵感设计师"列为 P1/C 级增强，并明确要求：
**若平台无法提供合适的运行时 AI 能力，应隐藏不可用入口，保留全部数学游戏与工坊功能；
不得用固定内容伪装真实大模型调用。**

本次开发环境无法确认一条满足以下全部条件的通道：

1. 不需要最终用户自备密钥；
2. 密钥只存在于服务端，不进客户端 bundle；
3. 可限流、可超时、可降级；
4. 返回内容经过严格 Schema 校验后才进入几何引擎。

因此选择**不实现、不露出**，并在 `docs/AI_INTEGRATION.md` 中记录若要实现所需的服务端架构、
数据契约、安全与成本约束。这不是"忘记做"，而是"不愿意做一个假的"。

## 四、评选相关声明

- 本作品**没有**使用任何第三方生成式图片、视频或 3D 素材。
- 所有截图来自真实运行的页面（`tools/ui_check.py` 与 `tools/level_check.py` 自动捕获）。
- 所有几何图形由代码实时计算，不存在"预置窗花图片"。
- 研究灵感来自公开论文与作者主页，未使用其图片、字体或源码（见 `references_licenses.md`）。
