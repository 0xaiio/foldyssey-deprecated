# 60 秒演示脚本（Demo Script）

> 目标：不讲技术栈，也能让人明白这是"数学可验证的数字剪纸游戏"。
> **脚本中的每一步在当前版本都能真实拍到**，不需要想象功能填空。

## 分镜

| 时间 | 画面 | 操作 | 字幕 / 旁白 |
|---|---|---|---|
| 0–5s | 首页首屏，红色方纸 + 中心菱形孔洞 | 静止 | 这一张纸，能剪出什么？ |
| 5–12s | 进入第 3 关，点"折叠" | 纸真的折成四层纸包 | 先折起来：左折右，再下折上 |
| 12–16s | 纸包上的切线与两个手柄 | 拖动端点旋转，拖到 45° | 一条直线，只能剪一刀 |
| 16–21s | 点"剪一刀"，切口区域变暗 | 剪下的三角形被移除 | 剪去纸包的内角 |
| 21–28s | 点"展开"，四层依次打开 | 展开动画 | 展开——四层各留下一块 |
| 28–32s | 定格：红纸中央的菱形孔洞 | 判定卡出现"完全吻合" | 孔洞 = \|x\|+\|y\| < d，面积 2d² |
| 32–40s | 第 6 关：把方纸剪成菱形 | 拖动偏移到 0.707，剪、展开 | 反过来想：不是挖洞，是剪掉四个角 |
| 40–50s | 工坊：加一刀、换配色、导出 | 点"导出 SVG" | 叠加多刀、换配色、导出真矢量 |
| 50–56s | 我的作品 / 手机画面 | 切到手机视口 | 手机也能拖，作品存在你自己的浏览器里 |
| 56–60s | 品牌页 + 标语 | — | 一刀万象 Foldyssey · Fold. Snip. Unfold. Wow! |

## 录制顺序（建议一次录完，再剪）

1. 打开 `#/`，等动画进入"菱形孔洞"状态（首帧即为成品）。
2. 点"立即剪一刀" → 第 1 关；在关卡栏点"菱形奇迹"跳到第 3 关。
3. 折叠 → 调整 → 剪 → 展开；**不要剪辑掉判定出现的那一帧**。
4. 关卡栏点"方中取菱"，重复一次（这次展示"接近 → 完全吻合"的调整过程更有说服力）。
5. 顶部导航进"剪纸工坊"：点"加一刀"、点一个美学预设、点"导出 SVG"（浏览器会下载文件，录到下载提示即可）。
6. 进"我的作品"展示刚保存的作品。
7. 把浏览器窗口缩到 390 宽（或用开发者工具设备模式）展示手机布局。

## 字幕规范

- 中文为主，关键术语附英文（Fold / Snip / Unfold）。
- 不出现"AI 生成"字样——本作品运行时没有 AI。
- 不出现未实现功能的描述。
