# ADR-0002：SVG + 矩阵插值做折叠动画，而不是动画库时间轴

- 状态：已采纳
- 日期：2026-10-30

## 背景

折叠动画必须与几何状态严格一致：动画的终点就是 `patch.transform`，不能是"另一套看起来差不多的关键帧"。

## 决策

- 渲染用 SVG `<path>` + `transform="matrix(...)"`。
- 动画由 `patchTransformAt(patch, progress)` 计算：把反射矩阵插值为 `diag(1-2p, 1)`。
- `motion` 只用于页面/卡片级微交互，不承担纸张动画。

## 理由

`p = 0.5` 时缩放为 0，正是"纸边翻起、正对观察者"的正交投影。这让 2.5D 折叠在数学上是**正确投影**，
而不是淡入淡出。用关键帧库反而更容易与几何脱节。

## 后果

- 正面：任意时刻的位置都能用公式复算；暂停/重播无需保存中间状态。
- 负面：需要自己处理层序与遮挡；不支持自由旋转相机。
