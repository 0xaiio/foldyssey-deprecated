# ADR-0004：开发期模型与运行期模型严格分离

- 状态：已采纳
- 日期：2026-10-30

## 背景

"用 AI 做了这个作品"与"这个作品里有 AI"是两件事。混为一谈是最常见的参赛披露问题。

## 决策

- 开发期：使用 WorkBuddy 的编程模型协助开发（需求、几何、代码、测试、文档）。
- 运行期：**不调用任何模型**；没有入口、没有密钥、没有网络请求。
- 披露：`submission/ai_usage_disclosure.md` 分两栏陈述，`docs/AI_INTEGRATION.md` 记录若实现的边界。

## 后果

- 正面：断网、限流、模型下线都不影响作品；不存在密钥泄露面。
- 负面：少了一个"AI 亮点"；但换来了"每个图案都能被验证"这一更强的卖点。
