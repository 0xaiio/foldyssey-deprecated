# ADR-0003：一刀挑战与自由剪纸的语义隔离

- 状态：已采纳
- 日期：2026-10-30

## 背景

"一刀"有严格定义：折叠纸包中的**一条完整直线** + 明确的移除半平面。
工坊允许多刀、允许更自由的创作，但两者的物理语义不同，混在一起会让"一刀"变成营销词。

## 决策

- **Puzzle**：`foldPreset` + 单个 `StraightCut`；目标由标准解正向构造；评分用 IoU。
- **Studio**：`foldPreset` + `StraightCut[]`（多刀，逐刀作用于上一刀后的纸包）；不做评分。
- 两者共用同一套 `applyCut` / `unfoldPatches`，但**不共享关卡数据**。
- 工坊不使用"一刀"字样；导出标签写"折剪方案已验证（几何层）"。

## 后果

- 正面：不会出现"用多刀作品冒充一刀关卡"的情况。
- 负面：工坊的多刀结果需要"逐刀折叠—剪切"的手工步骤，`手工制作卡` 已按刀序列出。
