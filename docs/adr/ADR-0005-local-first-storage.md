# ADR-0005：本地优先存储与隐私边界

- 状态：已采纳
- 日期：2026-10-30

## 背景

作品集需要持久化。引入账号/云数据库会带来：登录门槛、隐私面、后端运维、发布复杂度。

## 决策

- 作品与进度存 `localStorage`（`foldyssey.gallery.v1` / `foldyssey.progress.v1`）。
- 只存**结构化参数** + 一份派生路径缓存；不存位图。
- 读取时逐字段校验；未知版本拒绝载入而不是猜测。
- 不引入云数据库、不做账号体系。

## 替代方案

| 方案 | 为什么不用 |
|---|---|
| Supabase / 云数据库 | 首版无多人协作需求；会把静态站变成需要后端与鉴权的应用 |
| IndexedDB | 容量更大但 API 复杂；当前数据量（每件几百字节）远未触及 localStorage 上限 |
| 导出文件即存储 | 用户体验差（每次都要选文件） |

## 后果

- 正面：零后端、零登录、零追踪；发布即静态托管。
- 负面：换设备不同步；清缓存会丢作品。已在 UI 与文档中提示"先导出 SVG 留档"。
