# ADR-0001：二维精确几何优先，不引入纸张物理引擎

- 状态：已采纳
- 日期：2026-10-30

## 背景

折剪的最终结果是一个**平面图形**。纸张在折叠过程中的弯曲、厚度、弹性并不改变"哪些点被剪掉"这个集合运算结果。

## 决策

首版只实现二维精确几何：等距变换 + 多边形布尔运算。不引入 Matter.js / Rapier 等物理引擎，也不引入 Three.js。

## 替代方案

| 方案 | 优点 | 为什么不用 |
|---|---|---|
| 物理引擎模拟柔性纸 | 视觉真实 | 与"剪完是什么形状"无关；调试成本极高；无法保证面积正确 |
| Three.js 三维折叠 | 立体感强 | 首版二维/2.5D 已能表达折叠；三维会引入相机、光照、深度排序的额外风险 |
| 位图绘制 | 实现简单 | 无法保证孔洞拓扑、无法导出真矢量、无法做几何评分 |

## 后果

- 正面：面积、拓扑、对称性都可以用断言验证；导出即真矢量。
- 负面：折叠动画是"正交投影下的翻转"，不是物理仿真；已在 UI 与文档中如实说明。
