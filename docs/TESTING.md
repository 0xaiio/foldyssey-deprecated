### 关卡一致性测试

`levels.test.ts` 对每一关断言：

- 标准解 → `verdict === 'perfect'` 且对称差 < 1e-9；
- 初始切线 **不** 已通关（否则关卡没有挑战）；
- 随机无关切线 → `miss`；
- 目标面积在合理区间；黄金关卡有 4 重对称；终章关卡是内接菱形。

## 3. 视觉与发布验收（P0）

视口矩阵：

| 设备 | 尺寸 | 检查点 |
|---|---|---|
| 桌面 | 1440×900 | 首屏完整、无横向溢出、按钮可点 |
| 手机 | 390×844 | 纸张不溢出、切线手柄可拖、按钮 ≥ 40px |
| 窄屏 | 360×740 | 无内容被裁切 |

检查项：

- `document.documentElement.scrollWidth <= window.innerWidth`；
- 控制台无 error / 未捕获异常；
- `prefers-reduced-motion: reduce` 下不强制播放动画；
- 主要按钮有焦点样式（`focus-visible`）。

工具：`tools/ui_check.py`（Edge headless + CDP），产出 `.artifacts/*.png` 与 `report.json`。

## 5. 不做什么

- 不用像素相似度代替几何 IoU（有可靠几何区域时）。
- 不把随机测试当作黄金样例的替代。
- 不在未执行的情况下写"测试通过"。
