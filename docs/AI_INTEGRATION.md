# 运行时 AI 集成（AI_INTEGRATION）

**状态：未实现（有意为之）。**

本文记录"为什么没有"，以及"如果要做，边界在哪里"。这不是一份待办清单，而是一份决策记录。

---

## 1. 结论

本版本**不在作品运行时调用任何大模型**：

- 界面中没有 AI 入口、没有"生成中"动画、没有隐藏的 API 调用。
- 客户端 bundle 中没有任何模型密钥或端点。
- 所有图案由 `src/geometry` 的确定性算法生成，可复现、可验证。

## 2. 原因

| 约束 | 说明 |
|---|---|
| 无安全通道 | 本会话无法确认一条"不需要用户自备密钥"、可限流、可服务端保管密钥的运行时模型通道 |
| 密钥不能进前端 | 纯静态网站的浏览器端无法隐藏任何 API Key；公开仓库 + 分享链接会让泄露必然发生 |
| 不能伪装 | 需求文档明令禁止"用固定内容伪装真实大模型调用" |
| 优先级 | AI 属于 Gate C；Gate A 的数学正确性与发布优先级更高 |

## 3. 如果未来要实现

### 3.1 架构

```text
浏览器  ──POST /api/design──▶  服务端（持有密钥、限流、超时）
                                   │
                                   ├─ 系统提示词 + 用户主题
                                   ├─ 模型返回 JSON（严格 Schema）
                                   ├─ 服务端 Schema 校验 + 白名单枚举
                                   └─ 返回参数（不含任何可执行内容）
浏览器  ──参数──▶ 几何引擎 ──▶ 图案（可编辑、可导出）
```

模型只产出**参数**，不产出路径、不产出 SVG、不产出代码。

### 3.2 数据契约（草案）

```json
{
  "theme": "spring_festival",
  "style": "traditional_papercut",
  "foldPreset": "orthogonal2",
  "symmetry": { "type": "mirror", "axes": ["x", "y"] },
  "palette": { "paper": "#B93645", "background": "#F8F3E9" },
  "cuts": [
    { "nx": 0.7071, "ny": 0.7071, "offset": 0.24, "removedSide": "negative" }
  ],
  "title": "八瓣迎春"
}
```

校验规则：

- `foldPreset` ∈ 四个已实现预设；
- `cuts.length` ≤ 6；`offset` ∈ [-1.6, 1.6]；法向量归一化后有限；
- 颜色必须匹配 `^#[0-9a-fA-F]{6}$`；
- 标题 ≤ 40 字符，做 XML 转义；
- **未知字段拒绝**（而不是忽略），避免模型"自由发挥"。

### 3.3 安全与成本

- 服务端：请求体 ≤ 2 KB、单 IP 每分钟 ≤ 6 次、单次超时 12 s、全局日预算上限。
- 提示词注入：系统提示固定，用户输入只作为"主题描述"字段拼接，且长度受限；
  返回内容不进入 DOM 的 HTML 通道（只用 React 文本节点）。
- 失败降级：超时/限额/解析失败 → 明确提示 + "改用预设模板"按钮，绝不影响一刀挑战与工坊。

### 3.4 验收（实现时才适用）

- 正常输入 → 合法 JSON → 生成可编辑、可导出的图案；
- 越界参数 / 未知 motif → 拒绝并有可读错误；
- 断网、429、500 → 核心玩法不受影响；
- 未登录用户无需提供任何 Key。

## 4. 披露口径

- **开发期**：使用 WorkBuddy 的编程模型协助需求拆解、几何推导、编码、测试与文档。
- **运行期**：无模型调用。
