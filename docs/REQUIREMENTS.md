# 需求规格（REQUIREMENTS）

> 本文是**唯一的需求编号来源**。`TASKS.md` 用同一套 ID 追踪状态，`PROJECT_STATUS.md` 汇总里程碑。
> 优先级：**P0** = Gate A 最低上线闸门；**P1** = Gate B；**P2** = Gate C。
> 任何一项若未完成，必须在 `TASKS.md` 中标为「未完成 / 部分完成 / 受阻」，不得删除。

## 1. 几何内核（GEO）

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| REQ-GEO-001 | 纸张模型：`P = [-a,a]²`，`a=1`，以原点为中心，y 轴向上 | P0 | 面积 4.0000；所有几何函数只接受模型坐标 |
| REQ-GEO-002 | 等距变换：每层记录 `f(x)=Rx+t`、逆变换、折叠历史、层序 | P0 | `RᵀR=I`；`det=±1`；逆变换可还原顶点（误差 <1e-9） |
| REQ-GEO-003 | 四种固定折法：none / vertical / horizontal / orthogonal2 | P0 | 正交双折得 4 层、纸包面积 1.0 |
| REQ-GEO-004 | 直线剪切 = 半平面移除，逐层裁剪后逆映射 | P0 | 每层独立裁剪；剪下面积 = 各层之和 |
| REQ-GEO-005 | 展开 = 各层原始区域的并集 | P0 | 无裁剪时展开面积 = 4.0000 |
| REQ-GEO-006 | 黄金样例：正交双折 + `u+v<d` → `\|x\|+\|y\|<d` | P0 | 顶点 `(±d,0),(0,±d)`；面积 `2d²`；剩余 `4-2d²`；两轴对称 |
| REQ-GEO-007 | 多边形布尔运算封装（union/intersection/difference/xor） | P0 | 退化输入不崩溃；失败有确定性降级并计数 |
| REQ-GEO-008 | 评分：IoU 与对称差比 | P0 | 相同区域 IoU=1；明显错解 <0.9；空集有定义 |
| REQ-GEO-009 | SVG 路径导出（含孔洞） | P0 | 使用 `fill-rule="evenodd"`；孔洞为独立内环 |
| REQ-GEO-010 | 退化输入防护：NaN/Inf、零法向量、零面积、切线不接触 | P0 | 不抛异常；不误删纸张 |

## 范围边界（明确不做）

- 任意折叠（斜向折线、自由拖拽折痕）、曲线切口、多段折线切口
- 纸张物理仿真（厚度、弹性、重力、起皱）
- 账号体系、云同步、在线作品广场
- 运行时大模型（见 A-001）
- 微信小程序版本（首版只做网站应用）
